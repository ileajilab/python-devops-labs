
# Python DevOps Labs

30 days of hands-on Python automation projects.

## Learning Objectives
- Python fundamentals
- Linux administration automation
- AWS automation with Boto3
- DevSecOps scripting
- API integration
- CI/CD automation

## Day 1: System Information Collector

A Python script that retrieves:
- Hostname
- Operating system
- OS version
- CPU count
- Username
- Python version
- Machine architecture
- Current date and time

### Run
```bash
python3 day01/system_info.py
```
